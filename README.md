# Child Stunting and Socioeconomic Factors

Country-level analysis of child stunting using the Child Malnutrition with Socioeconomic Factors dataset.

307 rows, 77 countries. The useful output is the pattern in the charts: which countries sit at the high end of stunting prevalence, and how the average moves from 2000 to 2023. Poverty rate and fertility rate were the socioeconomic factors most discussed alongside that risk.

## What I worked on

- Business understanding and the project question
- Feature engineering
- Random Forest model and feature-importance review
- Streamlit page and the written conclusion

## Tools

Python, Pandas, scikit-learn, Random Forest, Streamlit
